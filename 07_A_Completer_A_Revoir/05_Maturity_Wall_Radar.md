# Radar dette et maturités

## Objectif

Créer un système de prospection qui repère les actifs sous pression de refinancement avant que le marché ne les voie.

## Idée centrale

```text
On ne cherche pas seulement quel immeuble acheter.
On cherche où la structure de dette va forcer une décision.
```

## Données à suivre

- adresse ;
- type d'actif ;
- marché ;
- propriétaire / borrower ;
- lender ;
- date d'acquisition ;
- montant estimé ;
- maturité probable ;
- LTV estimée ;
- occupancy ;
- DPE ;
- capex probable ;
- signaux faibles ;
- contact broker / syndic / avocat / entreprise.

## Proxies utiles

- acquisition 2018-2021 ;
- dette typique 5-7 ans ;
- hausse des taux ;
- baisse valeur ;
- vacance ;
- travaux énergétiques lourds ;
- lender qui réduit son exposition.

## À compléter

- premier marché cible ;
- sources publiques ;
- sources terrain ;
- modèle de scoring ;
- seuils de stress ;
- processus de contact ;
- data room pré-deal.

## Garde-fou

Ne pas confondre stress de dette avec bon deal. Un actif peut être sous pression et rester mauvais.
