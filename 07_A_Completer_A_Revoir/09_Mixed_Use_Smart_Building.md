# Condo mixed-use et smart building

## Objectif

Conserver les idées de condo autonome, mixed-use et smart building comme bibliothèque long terme, sans complexifier le premier actif.

## Principes à garder

- réduction consommation avant production énergétique ;
- architecture passive ;
- ventilation naturelle ;
- orientation solaire ;
- ombrage ;
- mutualisation énergétique ;
- récupération chaleur ;
- eau pluie / eaux grises si faisable ;
- maintenance prédictive ;
- capteurs consommation ;
- services mutualisés ;
- revenus annexes.

## À ne pas faire au démarrage

- lancer un condo complexe comme premier test ;
- surinvestir dans tech non rentable ;
- empiler services sans preuve de demande ;
- confondre green premium et rentabilité réelle.

## À compléter

- cahier des charges phase 2 ;
- design principles ;
- seuil de taille où mutualisation devient rentable ;
- coûts CAPEX / OPEX ;
- partenaires techniques ;
- contraintes réglementaires eau / énergie ;
- modèle de revenus annexes ;
- preuves nécessaires pour finance verte.
