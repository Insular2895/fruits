# Build-up BTP - due diligence à préparer

## Objectif

Préparer la doctrine future d'acquisition de PME BTP, sans lancer de M&A avant que Fruits ait prouvé son exécution.

## Principe

Le build-up BTP est pertinent seulement si Fruits sait déjà :

- piloter un chantier ;
- mesurer coûts et délais ;
- imposer un reporting ;
- gérer BFR ;
- intégrer des équipes ;
- préserver la culture terrain.

## Critères cible à compléter

- taille minimale ;
- CA ;
- REX / EBITDA ;
- dépendance fondateur ;
- dépendance 1 ou 2 clients ;
- stabilité pluriannuelle ;
- réputation terrain ;
- carnet de commandes ;
- BFR ;
- qualité management intermédiaire ;
- compatibilité avec les besoins Fruits.

## Points issus des conversations

- Une boîte trop petite peut être plus risquée qu'une boîte moyenne.
- Vendeur retraite + profil technique = signal potentiellement positif.
- Les chiffres doivent être lus sur plusieurs années.
- Le BFR est un risque central.
- L'ERP / IT doit être harmonisé rapidement mais sans casser le terrain.
- Les métiers proches réduisent les frictions chantier.

## Séquence hypothétique

1. Projet Fruits 1 : sous-traitance disciplinée et data.
2. Projet Fruits 2 : intégration limitée d'un métier critique.
3. Projet Fruits 3 : MEP / HVAC si processus robuste.
4. Projet Fruits 4 : bois / préfabrication si coordination maîtrisée.

## À compléter

- checklist LOI ;
- grille d'audit BFR ;
- questionnaire vendeur ;
- scorecard management ;
- playbook 30 / 60 / 90 jours ;
- plan d'intégration IT ;
- clauses de garantie.
