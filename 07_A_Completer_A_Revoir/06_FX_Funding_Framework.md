# Framework FX et devises

## Objectif

Encadrer les idées de dette en devise sans les transformer en stratégie de base.

## Règle provisoire

```text
Phase 1 Fruits : dette simple, lisible, principalement EUR.
FX structuré : uniquement si le ticket, les revenus, le conseil, la banque et le hedge justifient la complexité.
```

## Cadre à compléter

Le coût réel doit inclure :

- taux du prêt étranger ;
- coût du hedge ;
- frais FX ;
- marge banque ;
- documentation ;
- collateral éventuel ;
- coût d'unwind / roll ;
- risque opérationnel.

## Outils à cadrer

- natural hedge ;
- forward ;
- NDF ;
- option FX ;
- collar ;
- cross currency swap ;
- dette locale.

## Points provisoires

- Actif et revenus locaux : dette locale en priorité.
- Actif EUR et recherche d'optimisation : JPY + collar seulement en cas avancé.
- DKK / CHF : plutôt défensif.
- CCS : stabilité, pas alpha.
- Advisor : utile seulement si économie nette supérieure au coût.

## À ne pas faire

- financer en JPY non couvert comme stratégie standard ;
- vendre une promesse de rendement FX ;
- mélanger dette immo simple et pari devise ;
- exécuter une structure sans cotation concurrente.

## Validations nécessaires

- banque de marché ;
- advisor indépendant si ticket suffisant ;
- avocat / documentation ;
- fiscalité ;
- stress tests FX.
