# BIM / ACV - workflow minimal

## Objectif

Définir une version minimale de BIM / ACV / data bâtiment avant de déployer une stack lourde.

## Principe

```text
Commencer par la preuve et la donnée utile.
Ajouter les outils lourds seulement quand le deal le justifie.
```

- Revit ;
- One Click LCA ;
- PlanRadar / Dalux ;
