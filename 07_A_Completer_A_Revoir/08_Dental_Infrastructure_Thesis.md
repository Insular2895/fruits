# Thèse infrastructure dentaire

## Objectif

Explorer la possibilité de traiter les cabinets dentaires comme une verticale d'infrastructure immobilière / équipement / services, sans contrôler l'acte médical.

## Intérêt potentiel

- cash-flow récurrent ;
- activité défensive ;
- bancabilité ;
- besoins en murs, travaux et équipements ;
- mutualisation achats / admin / outils ;
- financement par dette privée, RBF ou equity.

## Limite majeure

Fruits ne doit pas contrôler :

- diagnostic ;
- choix médical ;
- soins ;
- relation clinique ;
- décisions ordinales.

Statut : `to_review` avec avocat santé avant toute action.

## À compléter

- cadre réglementaire ;
- structure autorisée ;
- rôle exact de Fruits ;
- contrats possibles ;
- rentabilité par fauteuil ;
- CA par praticien ;
- coût assistants / logiciels / équipements ;
- BFR remboursement mutuelles / tiers payant ;
- risques de vacance praticien ;
- acquisition patients autorisée ;
- assurance et RC.

## Questions à trancher

- Cette verticale est-elle vraiment Fruits, ou un futur projet séparé ?
- Est-ce un sujet immobilier, dette privée, exploitation ou santé ?
- Quel niveau de contrôle est légalement acceptable ?
