# Green finance, carbone, biodiversité

## Objectif

Clarifier ce qui peut réellement aider Fruits : financement vert, subventions, crédits carbone volontaires, biodiversité, obligations de compensation.

## Doctrine provisoire

```text
Carbone = bonus et preuve ESG.
Financement vert = vrai levier financier.
Compensation = parfois obligation, pas revenu automatique.
```

## À séparer

### Financement vert

- prêt bonifié ;
- meilleur LTV ;
- maturité plus longue ;
- covenants plus souples ;
- accès à investisseurs Article 8 / Article 9 si preuves suffisantes.

### Subventions

- études ;
- rénovation énergétique ;
- démonstrateur ;
- innovation / industrialisation ;
- impact territorial.

### Crédits carbone volontaires

- potentiellement liés au stockage carbone ou à la réduction d'émissions ;
- one-shot ;
- incertains ;
- jamais base DSCR.

### Biodiversité / compensation

- peut être obligation si destruction / artificialisation / défrichement ;
- peut être contribution volontaire ;
- doit être validé par expert environnement / urbanisme.

## À compléter

- critères d'éligibilité par type d'actif ;
- sources officielles ;
- acteurs à contacter ;
- budget d'étude ;
- preuves nécessaires ;
- impact financier réaliste ;
- traitement dans le modèle financier.

## Questions à trancher

- Quel niveau ESG minimal pour le premier actif ?
- Faut-il viser un label ou seulement une amélioration mesurable ?
- Quels revenus / aides peuvent être inclus dans le scénario base, upside ou exclus ?

## Validations externes nécessaires

- bureau d'études environnement ;
- avocat urbanisme / environnement ;
- banque ou courtier financement vert ;
- fiscaliste si mécanisme de crédit / subvention impacte la structure.
