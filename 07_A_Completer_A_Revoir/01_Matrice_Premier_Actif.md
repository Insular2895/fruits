# Matrice premier actif

## Objectif

Comparer proprement les candidats pour le premier actif Fruits, sans transformer trop vite une préférence en décision.

## Candidats à comparer

- résidence étudiante ;
- colocation LMNP personnelle ;
- petit immeuble résidentiel ;
- actif mixte léger ;
- résidence gérée / opérée avec partenaire.

## Hypothèse actuelle

La résidence étudiante ressort comme candidat fort car elle offre :

- répétition ;
- standardisation ;
- demande locative lisible ;
- bancabilité ;
- compatibilité ESG ;
- data rapide sur les coûts et l'exploitation.

Statut : `hypothesis_to_test`.
