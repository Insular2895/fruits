# Conversation GPT - LMNP, colocation, track record

## Résumé source

La conversation étudie le premier bien personnel comme moyen de réduire le coût de vie, apprendre l'exploitation et construire un track record.

## Objectif du premier bien

Le premier appartement n'a pas besoin d'être ultra rentable immédiatement.

Objectifs :

- réduire coût de vie ;
- construire track record ;
- apprendre exploitation réelle ;
- capitaliser via remboursement crédit.

Cash-flow légèrement négatif acceptable si coût logement total est fortement réduit.

## Structure

Pour 1-3 premiers biens :

- LMNP réel en nom propre privilégié ;
- SCI IS rejetée au démarrage.

Raisons :

- simplicité bancaire ;
- amortissements ;
- fiscalité loyers ;
- revente plus simple.

## Endettement

SCI n'efface pas le taux d'endettement.

Ce qui aide réellement :

- cash-flow positif / neutre ;
- banque en calcul différentiel ;
- revenus stables ;
- apport ;
- loyers stables.

## Exemple conversationnel

Configuration :

- IDF ;
- neuf ;
- 3 chambres ;
- prix environ 250 kEUR ;
- propriétaire occupe 1 chambre ;
- 2 chambres louées.

Résultat :

- avec 2 chambres louées : environ -200 EUR / mois ;
- quand propriétaire quitte et 3 chambres louées : +500 à +600 EUR / mois.

## Charges

À facturer à consommation :

- eau ;
- électricité ;
- chauffage.

Internet plutôt inclus.

## Assurances

Essentielles conversationnelles :

- assurance emprunteur ;
- MRH ;
- PNO selon lecture.

GLI optionnelle au début si screening / garants / zone tendue.

## Long terme Fruits

Les LMNP servent :

- crédibilité ;
- preuve d'exécution ;
- apprentissage terrain.

Mais :

- pas véhicule de levée ;
- ne pas transférer probablement dans Fruits ;
- garder patrimoine perso séparé.
