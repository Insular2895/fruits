# Conversation GPT - Dette immobilière et maturity wall

## Résumé source

La conversation part de vidéos MSCI et valide que la dette immobilière peut être plus prédictive que l'actif seul pour détecter des opportunités.

Idée centrale :

```text
Ne pas seulement chercher un bon immeuble.
Chercher où la structure de dette force une décision.
```

## Concepts clés

### Mur de maturité

- prêts faits en 2018-2019 ;
- maturité typique 5-7 ans ;
- refinancement 2025-2027 ;
- si taux hauts + valeurs basses + banques strictes = stress.

Conséquences :

- ventes forcées ;
- recapitalisations ;
- restructurations ;
- décotes.

### Radar de stress

Colonnes proposées :

- asset ID / adresse ;
- property type ;
- market ;
- borrower ;
- lender ;
- origination date ;
- maturity date ;
- loan amount ;
- LTV estimé ;
- occupancy ;
- notes / signaux faibles.

### Proxies

Même sans maturité exacte :

- achat 2018 ;
- dette 5-7 ans ;
- stress probable 2025-2027.

### Lenders

Suivre les lenders :

- réduction d'exposition ;
- refus refinancement ;
- vente de prêts ;
- contraintes capital réglementaire.

### CMBS

- pool de prêts immobiliers commerciaux titrisés ;
- special servicing ;
- restructurations plus mécaniques et visibles.
