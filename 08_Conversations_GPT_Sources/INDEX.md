# Conversations GPT - sources à exploiter pour Fruits

## Rôle

Cette section garde la trace précise des résumés de conversations GPT fournis par l'utilisateur.

Contrairement aux notes de consolidation, chaque fiche conserve le contexte de la conversation d'origine :

- ce qui a été discuté ;
- ce qui est utile pour Fruits ;
- ce qui ne doit pas être transformé en décision sans validation ;
- les sections Fruits impactées.

## Statut

Toutes les fiches sont `historical_to_review` ou `draft_to_validate`.

Cela signifie :

- utile comme mémoire de travail ;
- non validé comme décision ;
- potentiellement incomplet ou obsolète ;
- à relire avant intégration opérationnelle.
