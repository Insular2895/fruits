# Conversation GPT - Condos autonomes, mixed-use, smart building

## Résumé source

La conversation compare des modèles mondiaux de condos / immeubles autonomes et conclut que le futur rentable ressemble davantage à une plateforme immobilière autonome qu'à un condo de luxe classique.

## Modèle cible

Mixed-use sustainable smart condo :

- résidentiel ;
- commerces ;
- services ;
- coworking ;
- énergie mutualisée ;
- data centralisée ;
- gestion IA ;
- autonomie partielle eau / énergie.

## Modèles cités

### Primavera Residences

- condo mixte ;
- design bioclimatique ;
- ventilation naturelle ;
- réduction climatisation ;
- photovoltaïque ;
- brise-soleil.

Enseignement : design passif avant technologie.

### Linked Hybrid

- géothermie ;
- mix logements / services / commerces ;
- mini-ville verticale ;
- mutualisation rentable à grande taille.

### HIKARI Lyon

- photovoltaïque toiture / façade ;
- stockage thermique ;
- smart grid ;
- géothermie ;
- récupération chaleur ;
- eau pluie.

Enseignement : pilotage intelligent de l'énergie.

### Dockside Green

- biomasse ;
- chauffage central mutualisé ;
- déchets ;
- brownfield redevelopment.

### Sky Green

- végétation intégrée ;
- sky gardens ;
- ombrage ;
- microclimat ;
- valeur perçue.

## Technologies prioritaires

- photovoltaïque ;
- batteries ;
- géothermie selon taille ;
- récupération chaleur HVAC ;
- PAC mutualisées ;
- orientation solaire ;
- ventilation croisée ;
- façade respirante ;
- capteurs consommation ;
- maintenance prédictive ;
- eau pluie / eaux grises.
