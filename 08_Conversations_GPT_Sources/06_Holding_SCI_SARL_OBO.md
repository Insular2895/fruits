## Holding

- Une holding détient des participations.
- Ce n'est pas une forme juridique en soi.
- Passive : détention / dividendes.
- Animatrice : pilotage + services réels avec substance.

Mécanismes évoqués :

- mère-fille si détention >= 5% ;
- intégration fiscale si détention >= 95%.

## SCI vs SARL de famille

- SCI : adaptée location nue, IR ou IS.
- SARL de famille : adaptée location meublée, BIC, contraintes famille.
- IS : amortissements mais revente potentiellement plus coûteuse.
- IR : plus simple plus-value particulier mais pas amortissement immeuble.

## Holding + SCI

Intérêt :

- remontée profits vers holding ;
- réinvestissement via compte courant d'associé ;
- remboursement CCA non assimilé à distribution.

Limite :

- intérêt maximal si réinvestissement ;
- faible intérêt si tout est sorti en cash personnel.

## Banque / levier

- SCI ne supprime pas l'analyse bancaire personnelle.
- Les banques demandent souvent caution.
- Holding peut structurer mais pas supprimer les contraintes.

## LMNP 2025

- Vigilance sur réforme plus-value / amortissements.
- Meublé peut rester intéressant sur loyers, mais intégrer revente/transmission.

## OBO

Définition :

- vendre à une société que l'on contrôle ;
- la société finance l'achat par dette + equity ;
- objectif : recycler l'equity en gardant le contrôle.

Conclusion conversationnelle :

- utile après actifs stabilisés ;
- peu pertinent au démarrage si bonne structure possible directement ;
- frais + fiscalité + banque + substance économique.
