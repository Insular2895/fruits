# Conversation GPT - VEFA, colocation, assurances

## Résumé source

La conversation clarifie un achat neuf en construction, probablement en VEFA, avec objectif d'habiter le logement et louer deux chambres.

## VEFA

- Le prêt n'est pas débloqué d'un coup.
- Les fonds sont débloqués selon appels de fonds.
- Pendant travaux : différé partiel possible.
- Pendant différé : intérêts intercalaires + assurance emprunteur.
- À livraison : crédit normal capital + intérêts + assurance.

Exemple conversationnel :

- prêt 250 kEUR ;
- taux 3,4% ;
- chantier 18 mois ;
- intérêts intercalaires environ 8,5 kEUR hors assurance.

## TMA

Travaux modificatifs utiles avant livraison :

- prises électriques ;
- RJ45 ;
- sorties plafond ;
- cloisons ;
- SDB / cuisine ;
- alimentation îlot ;
- coin TV.

Principe :

- encastré / technique : mieux avant livraison ;
- finitions déco : possible après.

## Colocation propriétaire occupant

Le propriétaire n'est pas colocataire.

Structure :

- propriétaire occupant ;
- bailleur ;
- deux locataires ;
- propriétaire hors bail.

Solution conversationnelle privilégiée :

- bail unique pour les deux locataires ;
- clause de solidarité si adaptée ;
- parties communes incluses.

## Assurances

Pour le propriétaire :

- assurance emprunteur ;
- MRH propriétaire occupant ;
- MRH doit couvrir location de chambres / colocation et RC bailleur ;
- PNO peut être redondante si MRH couvre bien, sinon utile.

Pour les locataires :

- assurance habitation locataire obligatoire ;
- attestation à fournir.

GLI :

- souscrite par bailleur ;
- fonctionne souvent mieux avec bail unique ;
- ne pas utiliser de montage fictif d'auto-location.

Alternative :

- Visale ;
- caution solidaire ;
- caution bancaire ;
- dépôt de garantie.
