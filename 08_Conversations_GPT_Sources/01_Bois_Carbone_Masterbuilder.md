## Points précis extraits

### Bois / carbone

- Le bois est un levier technique, pas le coeur du modèle.
- 1 m3 de bois peut être traité comme environ 1 tonne de CO2 stockée dans l'idée de conversation.
- Ne pas parler de quotas carbone.
- Parler plutôt de crédits carbone volontaires, si le projet est éligible.

### Revenus carbone

- Ordre de grandeur conversationnel : 10-15 EUR / m2.
- Immeuble moyen : environ 30-90 kEUR possible selon hypothèses.
- Revenu one-shot.
- Pas annuel.
- Pas récurrent.
- Ne doit pas être base du DSCR.

### Financement vert

- Le vrai levier n'est pas le crédit carbone.
- Subventions possibles : 50-200 kEUR pour démonstrateur.
- Prêts bonifiés : -0,5 à -1 point de taux.
- Financement vert : LTV potentiellement +5 à +10 points, maturité plus longue, meilleure lecture bancaire.

### Stratégie progressive

- Immeuble 1 : laboratoire, data, playbook, début certification.
- Immeuble 2 : acquisition / intégration béton.
- Immeuble 3 : HVAC / MEP.
- Immeuble 4 : bois intégré et certification carbone pleinement activée.

### Premier produit

- Résidence étudiante ressort comme meilleur choix de départ :
  - répétition ;
  - standardisation ;
  - data rapide ;
  - bancable ;
  - compatible ESG ;
  - rendement conversationnel 5,5-7,5%.
- Condo avec services jugé trop complexe pour la phase 1.
