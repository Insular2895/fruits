# Conversation GPT - Build-up boring business BTP

## Résumé source

La conversation extrait les enseignements d'une vidéo / transcription sur le build-up de PME BTP type boring business.

Idée centrale :

```text
Le build-up fonctionne si l'on réduit le risque opérationnel et crée de la valeur par complémentarité métier, pas seulement par arbitrage de multiple.
```

## Taille des cibles

Point fort :

- une boîte de 1 MEUR peut être plus risquée qu'une boîte de 5 MEUR ;
- trop petite = dépendance fondateur, 1-2 personnes, quelques clients.

Repères conversationnels :

- 10 personnes environ 1 MEUR de CA ;
- environ 100 kEUR CA / personne ;
- en dessous, difficile d'absorber direction / frais fixes.

## Valorisation

- petite boîte bâtiment : 3-5x REX conversationnel ;
- multiple peut monter avec taille, structure, moindre dépendance fondateur ;
- arbitrage de multiple insuffisant sans opérationnel.

## Critères cible

- vendeur part à la retraite ;
- vendeur technique ;
- chiffres stables pluriannuels ;
- réputation terrain ;
- attention aux comptes manipulables via avancement chantier.

## Création de valeur post-acquisition

Trois moteurs :

1. Organisation : planification, checklists, logistique.
2. Interfaces métiers : moins de friction chantier.
3. Standardisation outillée : ERP, devis, planning, coûts, facturation.

Outil cité : Granit ERP chantier.

## Day 1

- changer IT / logiciel rapidement ;
- ajuster direction si besoin ;
- message de continuité ;
- revoir les principaux clients ;
- rassurer techniquement.

## BFR

- risque majeur en croissance ;
- banques financent souvent mieux acquisition que BFR ;
- leviers : acomptes, délais paiement, pilotage trésorerie, négociation fournisseurs.

## Taille groupe

- cible par entité : 5-10 MEUR CA ;
- environ 30 personnes ;
- éviter déséconomies d'échelle.
