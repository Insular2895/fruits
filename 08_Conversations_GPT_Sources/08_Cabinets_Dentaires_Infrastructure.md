# Conversation GPT - Cabinets dentaires comme infrastructure

## Résumé source

La conversation explore l'idée d'utiliser Fruits pour financer, structurer et optimiser des cabinets dentaires sans exercer la médecine.

## Thèse

Le cabinet dentaire peut être :

- actif défensif ;
- cash-flow récurrent ;
- faible défaut ;
- très finançable ;
- scalable via structure financière et opérationnelle.

## Économie conversationnelle

Coût :

- création : 250-500 kEUR ;
- reprise : 300-800 kEUR.

CA :

- classique : 300-500 kEUR ;
- optimisé : 600 kEUR - 1 MEUR+.

Rentabilité :

- net optimisé : 25-45%.

## Montages évoqués

- full financing + revenue share ;
- 60/40 financing + equity + RBF ;
- equity + management fees ;
- SCI immo optionnelle ;
- SPV santé / dentaire ;
- SEL du dentiste.

## Contrats

- bail professionnel / commercial ;
- contrat de services ;
- contrat RBF / revenue share.

## Limite légale majeure

Fruits ne doit pas contrôler :

- soins ;
- diagnostics ;
- décisions médicales.

Fruits peut seulement viser :

- immobilier ;
- financement ;
- admin ;
- achats ;
- data ;
- outils ;
- infrastructure.

## Infos terrain dentiste

- mix jeunes / expérimentés ;
- préavis / durée minimale possible ;
- coûts praticien environ 60% sur analyses, labo, prothèses, consommables ;
- structure environ 40% sur matériel, fauteuils, locaux ;
- recrutement via écoles, groupes Facebook, réseaux ;
- investissement évoqué : environ 2 MEUR pour plateau structuré.

## Questions restantes

- rentabilité par praticien ;
- rentabilité par fauteuil ;
- CAC / Doctolib ;
- coûts fixes / variables ;
- ROI outils ;
- réglementation travail ;
- remboursements / mutuelles / BFR ;
- publicité médicale ;
- RH / incentives ;
- worst case.
