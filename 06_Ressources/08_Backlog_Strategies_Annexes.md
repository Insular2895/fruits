# Backlog strategies annexes

## Role

Cette note remplace les anciennes fiches dispersees de `07_A_Completer_A_Revoir`.

Elle garde les sujets utiles, mais les separe clairement du socle valide Fruits. Rien ici ne vaut decision projet sans validation explicite.

## Ordre de traitement

1. Matrice premier actif : colocation LMNP, petit immeuble, residence etudiante, actif mixte leger.
2. Donnees chantier : couts reels, incidents, cadences, fournisseurs, photos, ecarts budget.
3. VEFA / TMA / LMNP / colocation : apprentissage personnel sans melanger patrimoine perso et Fruits.
4. Radar dette / maturity wall : opportunites liees aux refinancements difficiles.
5. BIM / ACV minimal : outil de preuve et de pilotage, pas stack lourde au depart.
6. Green finance, carbone, biodiversite : financement vert d'abord, credits comme upside.
7. Build-up BTP : later stage apres track record travaux.
8. FX / devise : outil sophistique, jamais base du modele.
9. Sante / dentaire : infrastructure, locaux, materiel, services, pas operation medicale.
10. Mixed-use smart building : produit long terme, apres methode repetable.

## Vision long terme a garder

Fruits peut devenir :

- groupe immobilier integre europeen ;
- developpeur d'immeubles ;
- controleur partiel de la chaine construction ;
- acquereur de PME strategiques ;
- exploitant de batiments ;
- plateforme M&A et data-driven.

Limite : cette vision ne doit pas modifier le socle actuel tant que les premiers actifs, le reporting et la capacite operationnelle ne sont pas prouves.

## Premier immeuble comme laboratoire

Le premier projet sert a :

- tester les methodes ;
- comprendre les couts reels ;
- identifier les goulots ;
- documenter les process ;
- selectionner partenaires et sous-traitants ;
- construire dashboards et data room ;
- creer un playbook.

Hypothese Hubert / industrialisation :

- prefabrication ;
- standardisation ;
- automatisation ;
- reduction du travail terrain ;
- optimisation des flux.

Le gain de main-d'oeuvre terrain reste une hypothese a verifier, pas un chiffre pitchable.

## Produits long terme

Principes a garder :

- residentiel ;
- commerces ;
- services ;
- coworking ;
- energie mutualisee ;
- data centralisee ;
- gestion IA ;
- autonomie partielle eau / energie.

```text
design passif et pilotage energetique avant technologie decorative
```

### Cabinet dentaire / sante infra

Fruits peut travailler sur :

- locaux ;
- materiel ;
- plateforme ;
- services ;
- administratif ;
- recrutement non medical ;
- planning ;
- reporting.

Fruits ne doit pas se presenter comme operateur medical.

### BTP / green building tech

Approche materiaux possible :

- beton pour fondations, noyaux et stabilite ;
- bois / CLT pour elements repetables ;
- acier pour grandes portees ;
- prefabrication pour facades et modules.

Donnees chantier a capter :

- temps de pose ;
- consommation materiaux ;
- incidents ;
- couts reels ;
- cadence ;
- dechets ;
- erreurs ;
- rendement energetique.
