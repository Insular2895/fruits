# Diagnostic 360 - Projet Fruits

## Verdict court

Fruits est viable si le projet reste d'abord un opérateur immobilier discipliné, avec des SPV isolées, des réserves fortes, une dette senior prudente et des investisseurs rémunérés prioritairement mais sans promesse garantie.

Le risque principal n'est pas l'idée. Le risque principal est l'empilement trop rapide :

```text
dette senior + ADP + lombard + ETF + FX + BTP + subventions + santé
```

Tout peut être utile, mais pas tout en même temps, pas au stade 1.

## Corrections importantes intégrées

### Lombard

Ancienne logique trop agressive : LTV cible 40%, max 50%.

Version corrigée :

- LTV cible 20-25%.
- Maximum interne 30% sur portefeuille actions diversifié.
- Cash buffer 30-50% du lombard.
- Jamais pour financer salaire, déficit d'exploitation ou dette longue.

### ETF

Les simulations ETF ne doivent pas être présentées comme des résultats attendus.

Version corrigée :

- scénarios seulement ;
- aucun ETF actions dans les réserves nanties des SPV ;
- collar = outil de risque, pas rendement gratuit ;
- coût de collar variable selon volatilité, spreads, maturité et fiscalité.

### Actions de préférence

Le modèle est intéressant, mais doit rester juridiquement propre.

Version corrigée :

- rendement prioritaire cible, pas garanti ;
- SAS plutôt que SCI ;
- rachat prévu statutairement ;
- attention AMF / offre au public ;
- ne pas créer une dette déguisée.

### Usufruit / nue-propriété

Version corrigée :

- la NP protège économiquement le FO, mais n'est pas une sûreté au sens strict ;
- convention de démembrement obligatoire ;
- entretien, grosses réparations, assurances et travaux à cadrer.

### Sûretés

Ancien vocabulaire à éviter :

- PPD.

Version corrigée :

- hypothèque conventionnelle ;
- hypothèque légale spéciale du prêteur de deniers si applicable.

### Refinancement

Le refinancement est utile mais ne doit pas devenir une béquille.

Version corrigée :

- à modéliser dès l'achat ;
- à lancer 6-9 mois avant maturité d'une dette courte ;
- à utiliser pour sortir d'un bridge, rembourser un crédit vendeur ou racheter partiellement un investisseur ;
- jamais à présenter comme garantie de rachat ;
- toujours vérifier LTV, DSCR, frais, pénalités et réserves après refinancement.

### Rémunération Fruits / promote

Version corrigée :

- salaire via Fruits OpCo, pas prélèvement direct sur l'argent investisseur ;
- fees opérateur transparents, plafonnés et prévus au contrat ;
- promote / upside seulement après dette, réserves, retour capital investisseur et preferred return ;
- un 70/30 marché veut souvent dire 70% investisseur / 30% sponsor ;
- 70% en faveur de Fruits n'est défendable que si l'investisseur est plafonné, prioritaire ou déjà fortement protégé.

### Financeurs complémentaires

Financeurs ajoutés après audit :

- PSFP / crowdfunding : canal utile pour un bridge simple, mais soumis à cadre AMF/PSFP et à une communication risques stricte.
- Banque des Territoires / CDC : utile seulement si impact territorial réel ; pas un financeur de pur rendement résidentiel.
- SCPI / OPCI / SIIC : plutôt acheteurs de sortie ou partenaires d'actifs stabilisés que financeurs de lancement.
- Crédit vendeur : excellent outil opportuniste si le vendeur accepte un paiement différé, avec validation notaire/banque.
- Crédit-bail immobilier : pertinent pour immobilier d'exploitation, peu adapté à une foncière résidentielle passive.

## Cohérence mathématique - règles minimales

### Dette senior

Stade 1 :

- LTV cible : 55-65%.
- 70% seulement si actif très liquide, cash-flow solide et sortie évidente.

### Actions de préférence

Test minimum :

- couverture du rendement prioritaire cible > 1,50x en scénario normal ;
- couverture > 1,10x en scénario stress ;
- DSRA et réserve capex pleines avant distribution Fruits.

### DSCR

- Cible normale : > 1,30x.
- Minimum scénario bas : > 1,20x.
- Si < 1,20x : cash trap, pas de distribution Fruits.

### Réserves

- DSRA : 3-6 mois de dette.
- Capex/vacance : montant fixe ou % loyers.
- Réserve lombard séparée si lombard.

## Ce qui est empilable

### Empilement prudent stade 1

```text
Dette senior prudente
+ equity Fruits
+ ADP / UHNWI / FO
+ DSRA
+ réserve capex
```

Option opportuniste :

```text
+ crédit vendeur si le vendeur accepte
+ PSFP uniquement si le deal est court, simple et très documenté
```

### Empilement possible stade 2

```text
Dette senior ou private debt structurée
+ ADP / preferred equity
+ intercreditor
+ reporting mensuel
+ audit léger
```

Options stade 2 :

```text
+ crédit-bail immobilier si actif d'exploitation
+ Banque des Territoires si impact territorial fort
+ vente à SCPI/OPCI/SIIC si actif stabilisé
```

### Empilement possible stade 3

```text
Dette institutionnelle longue
+ JV fonds / assureur
+ ESG / financement vert
+ portefeuille stabilisé
+ audit externe
```

## Ce qui ne doit pas être empilé au départ

- Lombard personnel + dette senior + ADP sur le même cash-flow.
- Dette courte pour actif long.
- FX non couvert.
- ETF actions dans une SPV financée.
- BTP / santé / subventions avant track record immobilier.
- Rachat obligatoire des investisseurs sans source de financement identifiée.
- Refinancement supposé automatique ou basé sur une valorisation trop optimiste.
- Promote Fruits trop agressif avant track record.
- Fees fixes élevés + promote élevé sur le même deal.

## Stratégies documentées similaires

### Real estate preferred equity

Très courant dans l'immobilier institutionnel : une couche entre dette senior et common equity, avec priorité économique et rendement cible.

À reprendre :

- waterfall ;
- preferred return ;
- contrôle sur décisions majeures ;
- reporting ;
- rachat/refinancement.

À ne pas copier aveuglément :

- niveau de levier institutionnel trop élevé ;
- complexité intercreditor ;
- promesses de coupon trop fixes à des investisseurs privés.

### JV promote / GP-LP

Structure classique fonds immobiliers :

- LP apporte capital ;
- GP/Fruits opère ;
- LP reçoit capital + preferred return ;
- GP reçoit promote seulement après hurdle.

À reprendre :

- alignement ;
- hurdle ;
- clawback si nécessaire ;
- reporting ;
- budget annuel.

### Démembrement NP/UF

Plus naturel en France et pays civilistes. Très adapté aux investisseurs patrimoniaux qui veulent un droit réel plutôt qu'une promesse corporate.

À reprendre :

- simplicité ;
- sortie naturelle ;
- actif réel ;
- faible gestion investisseur.

À surveiller :

- fiscalité ;
- travaux/grosses réparations ;
- liquidité secondaire ;
- pricing économique vs barème fiscal.

## Priorité stratégique

1. Prouver 1-2 actifs simples.
2. Construire reporting et data room.
3. Lever via FO/UHNWI/ADP sur un deal propre.
4. Créer pool 5-10M.
5. Approcher private debt structuré et foncières.
6. Institutionnaliser seulement après KPI.

## Niveau de qualité actuel

Qualité stratégique : 8/10.

Le modèle est cohérent : actifs lisibles, SPV isolées, waterfall, réserves, reporting, investisseurs adaptés par stade.

Qualité investisseur-ready : 6,5/10.

Il manque encore pour être réellement finançable :

- modèles financiers par deal avec hypothèses vérifiables ;
- term sheets relues par avocat/notaire/fiscaliste ;
- data room type ;
- exemples chiffrés avec prix, loyers, charges, dette, fiscalité, vacance ;
- track record réel ;
- politique de conformité AMF/offre privée/PSFP.

Objectif raisonnable après mise en place de ces éléments : 8/10 investisseur-ready sur un premier deal simple.

## Conclusion

Le projet doit vendre une promesse simple :

> Fruits permet à des investisseurs patrimoniaux de financer des actifs immobiliers lisibles, dans des SPV isolées, avec une priorité économique claire, des réserves, un reporting mensuel et une sortie prévue.

Tout ce qui ne renforce pas cette phrase doit rester secondaire.
