# AVOCATS / CONSEILS

Cabinets possibles pour scale :
- Gide.
- Mayer Brown Paris.

Début :
- Cabinet Bremens : avocat + notaire.

À produire en templates :
- Term Sheet 2-4 pages.
- Facility Agreement.
- Security package.
- Management Agreement OpCo / SPV.
- Term sheet actions de préférence.
- Statuts SAS avec catégories d'actions.
- Pacte d'associés ADP / actions ordinaires.
- Reporting pack mensuel.

## Template Term Sheet
- use of proceeds ;
- structure SPV / ring-fencing ;
- waterfall ;
- DSRA / réserves ;
- covenants LTV / DSCR / liquidité ;
- sûretés ;
- events of default + cure periods ;
- distributions / cash trap ;
- management fees plafonnés et conditionnels ;
- non-recourse / limited recourse capé + step-down ;
- reporting.

## Security package - templates
- nantissement parts SPV ;
- cession / nantissement loyers ;
- nantissement comptes, incluant DSRA ;
- nantissement compte-titres monétaire optionnel ;
- liste Eligible Assets ;
- règles de contrôle ;
- intercreditor si plusieurs couches.

## Management Agreement OpCo / SPV
- périmètre réel des services ;
- frais plafonnés ;
- subordination à la waterfall / cash trap ;
- KPI / reporting.

## Reporting pack mensuel
- 1 page KPI ;
- rent roll ;
- DSCR / LTV ;
- DSRA ;
- capex / incidents ;
- relevés bancaires.

## Pack actions de préférence

À produire avec avocat :

- statuts SAS avec actions ordinaires et actions de préférence ;
- droits financiers des ADP : rendement prioritaire cible, priorité de distribution, priorité de liquidation si prévue ;
- droits politiques : vote aménagé, veto sur reserved matters, droit d'information ;
- mécanisme de rachat : date, initiative, formule, conditions, prime éventuelle ;
- pacte d'associés : waterfall, reporting, transferts, agrément, drag/tag, cas de défaut ;
- note investisseur : le rendement est prioritaire/cible, pas garanti ;
- validation du risque AMF / offre au public si levée auprès de plusieurs investisseurs.
