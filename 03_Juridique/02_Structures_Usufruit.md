# STRUCTURES DE BASE

## Usufruit classique

Structure :
- Le Family Office achète la nue-propriété.
- Fruits / SPV opérateur achète l'usufruit.
- Fruits finance l'UF via banque idéalement, ou via prêteur si négocié.
- Chacun détient juridiquement sa part.

Pendant la vie du deal :
- Fruits encaisse 100% des loyers.
- Le FO ne touche rien pendant la durée sauf accord spécifique.
- Le FO attend la fin du démembrement.

Fin naturelle :
- Remembrement automatique.
- Le FO récupère 100% du bien.
- Fruits perd son droit d'usage et d'exploitation.

Économie :
- FO : décote d'achat, revalorisation, inflation, zéro gestion.
- Fruits : spread locatif, cash-flow, fees éventuels.

## Portage d'usufruit

Structure :
- Le FO achète la NP.
- Le FO prête à Fruits le montant nécessaire pour financer l'UF.
- Le FO est propriétaire de la NP et créancier sur l'UF.

Pendant la vie du deal :
- Fruits encaisse les loyers.
- Fruits rembourse les intérêts et/ou le principal selon format.
- Formats possibles : interest-only, amortissement partiel, hybride.

À la revente ou sortie :
1. Remboursement du prêt UF.
2. Le FO récupère la valeur NP.
3. Surplus éventuel partagé selon waterfall.

Économie :
- FO : intérêts, double sécurité, revalorisation, priorité.
- Fruits : spread locatif, surplus éventuel, fees.
