# Structures usufruit

## Position Fruits

L'usufruit juridique est un outil specifique, pas la structure standard de tous les deals Fruits.

Structure standard :

```text
co-invest operateur avec logique d'usufruit economique
```

Exception possible :

```text
vrai demembrement NP / UF si actif stable, duree longue, FO patrimonial et fiscalite validee
```

## Usufruit economique

Cette logique peut etre obtenue par pacte et waterfall sans imposer un demembrement juridique.

Lecture :

- l'investisseur finance l'exposition patrimoniale ;
- Fruits exploite, gere et porte le risque operationnel ;
- Fruits conserve les revenus nets d'exploitation ;
- l'investisseur est prioritaire a l'exit ;
- Fruits negocie droit de preference, option ou streaming si l'actif est conserve.

Avantages :

- plus flexible que le demembrement strict ;
- compatible avec promote, fees et co-invest ;
- adaptable a 3, 5, 7 ou 10 ans ;
- plus lisible pour des produits exploites, travaux ou services.

## Usufruit juridique classique

Structure :

- le FO achete la nue-propriete ;
- Fruits ou une SPV operateur achete l'usufruit ;
- Fruits finance l'UF via banque, apport, portage ou preteur si negocie ;
- chaque partie detient juridiquement son droit.

Pendant la vie du deal :

- Fruits encaisse les loyers et revenus d'exploitation ;
- Fruits supporte charges, entretien, dette et reserves selon convention ;
- le FO ne touche rien pendant la duree sauf accord specifique ;
- le FO attend le remembrement ou une sortie organisee.

Fin naturelle :

- remembrement automatique ;
- le FO recupere la pleine propriete ;
- Fruits perd son droit d'usage et d'exploitation.

Point cle :

```text
Fruits ne capte pas les loyers bruts.
Fruits capte les revenus nets apres charges, dette, maintenance et reserves.
```

## Portage d'usufruit

Structure :

- le FO achete la NP ;
- le FO prete a Fruits tout ou partie du montant necessaire pour financer l'UF ;
- le FO est proprietaire de la NP et creancier sur l'UF.

Pendant la vie du deal :

- Fruits encaisse les revenus d'exploitation ;
- Fruits rembourse les interets et/ou le principal selon format ;
- formats possibles : interest-only, amortissement partiel, PIK partiel ou hybride.

A la sortie :

1. remboursement du pret UF ;
2. recuperation ou valorisation de la NP ;
3. surplus eventuel partage selon waterfall.

## Quand utiliser le vrai usufruit

Pertinent si :

- FO demande une logique patrimoniale forte ;
- actif stable ;
- duree 5-10 ans ou plus ;
- travaux limites ou tres cadres ;
- fiscalite validee ;
- convention notariee solide ;
- sortie ou remembrement clairement compris.

A eviter si :

- actif tres operationnel ;
- cash-flow incertain ;
- duree courte ;
- besoin de flexibilite ;
- promote complexe ;
- travaux lourds ;
- sortie non claire.

## Points juridiques a faire relire

- prix economique NP / UF ;
- fiscalite et valorisation ;
- entretien, grosses reparations et assurances ;
- travaux et changement d'usage ;
- suretes et recours ;
- consequences d'un defaut Fruits ;
- sortie anticipee ;
- option de rachat ou droit de preference.
