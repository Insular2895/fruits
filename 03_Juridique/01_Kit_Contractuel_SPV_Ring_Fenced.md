# KIT CONTRACTUEL STANDARD SPV / RING-FENCED

Ce kit sert de base commune. Il doit ensuite être adapté par investisseur.

## 1. Documents du binder

Constitution SPV :
- statuts SCI IS / SAS / SARL selon cas ;
- pacte d'associés si plusieurs investisseurs ;
- registre des décisions ;
- pouvoirs et délégations.

Contrats OpCo :
- Management Agreement ;
- mandat travaux / AMO si nécessaire ;
- convention de trésorerie seulement si autorisée, sinon interdite.

Financement :
- Term Sheet ;
- Loan Agreement ;
- Intercreditor si senior + mezz ou investisseurs multiples ;
- Conditions precedent : due diligence, assurances, valorisations.
- Si crédit vendeur : acte de vente, échéancier Balloon / Step / Zero, coût complet, cas de défaut, remboursement anticipé et reporting.

Sûretés :
- hypothèque conventionnelle ou hypothèque légale spéciale du prêteur de deniers si applicable ;
- hypothèque légale spéciale du vendeur si solde de prix immobilier ;
- cession de créances de loyers si applicable ;
- nantissement comptes bancaires + Account Control Agreement ;
- nantissement parts sociales / actions du SPV ;
- nantissement DSRA / réserves ;
- si portage UF : nantissement usufruit + mécanisme de réalisation.
- si portabilité vendeur : mainlevée/purge, substitution de sûreté, compte-titres nanti, haircuts, couverture, appels de marge et traitement des produits.

Cadre crédit vendeur : [Vente à terme / crédit vendeur — système Fruits](../04_Operationnel/12_Vente_A_Terme_Credit_Vendeur_Fruits.md). Toute substitution reste expérimentale avant validation du vendeur, du notaire, de l'avocat et des financeurs.

Comptes et cash management :
- compte loyers / operating ;
- compte DSRA ;
- compte capex/vacance ;
- compte-titres réserve monétaire nanti si autorisé ;
- compte dépôts de garantie locataires si utile.

Assurances :
- PNO ;
- multirisque immeuble ;
- RC ;
- GLI si pertinente ;
- cession des indemnités au prêteur / loss payee.

Reporting et contrôle :
- pack mensuel ;
- droit d'audit ;
- contrôle documentaire ;
- valuation périodique selon prêteur.

## 2. Clauses standard
- Non-recourse ou limited recourse capé.
- Aucun recours personnel sauf bad boy carve-outs.
- Pas de cross-collateral.
- Pas de cross-default groupe, sauf seuil matérialité clairement défini.
- Pas de cash pooling.
- Comptes dédiés.
- Waterfall mensuelle.
- Fees OpCo plafonnés et subordonnés.
- DSRA 3-6 mois.
- Réserve capex/vacance.
- Eligible Assets limités à cash, monétaire, T-Bills UCITS court terme.
- Covenants simples : LTV, DSCR, minimum liquidity.
- Cash trap si breach.
- Cure periods pour défauts techniques.
- Bad boy carve-outs limités : fraude, fausse déclaration matérielle, cash leakage, obstruction volontaire, actes illégaux volontaires.
- Offre de titres : vérifier AMF / prospectus / placement privé avant toute levée auprès de plusieurs investisseurs.
