# Rémunération Fruits / Waterfall / Promote

## Objectif

Définir comment Fruits se paie proprement, sans donner l'impression que l'argent investisseur sert à financer le train de vie du sponsor.

Principe central :

```text
Fruits ne se paie pas avant le deal.
Fruits se paie parce que le deal fonctionne.
```

## Structure propre

```text
SPV du bien
-> encaisse loyers / produit de vente
-> paie charges, dette, réserves, investisseurs
-> paie des fees transparents à Fruits OpCo
-> Fruits OpCo paie salaires et coûts d'équipe
-> Fruits Holding capte l'upside si le deal surperforme
```

Fruits doit distinguer :

- **fees opérateur** : rémunération du travail réel de gestion ;
- **salaire** : payé par Fruits OpCo, pas directement par la SPV à la personne ;
- **promote / performance fee** : rémunération de la surperformance ;
- **dividendes** : distribution plus tard, si le groupe est rentable.

## Salaire Fruits

Le salaire doit venir de Fruits OpCo, via des fees justifiés.

Sources possibles :

- management fee mensuel ;
- asset management fee ;
- property management fee ;
- fee travaux / project management ;
- sourcing / structuring fee ;
- refinancing / disposition fee si prévu ;
- performance fee seulement après hurdle investisseur.

Règle :

```text
La SPV paie une prestation réelle à Fruits OpCo.
Fruits OpCo paie les salaires.
```

Ce qu'il faut éviter :

```text
Investisseur met 150k
-> Fruits prélève directement un salaire personnel dessus
```

Ce qu'il faut faire :

```text
Investisseur met 150k
-> argent utilisé pour l'actif
-> l'actif génère loyers / valeur
-> Fruits facture des fees prévus et plafonnés
-> Fruits OpCo paie le salaire
```

## Waterfall des loyers

Les loyers ne sont distribuables qu'après les priorités.

```text
Loyers encaissés
-> charges obligatoires
-> dette senior / banque
-> DSRA
-> réserve capex / vacance
-> investisseur prioritaire : ADP, prêt privé, FO si prêt UF
-> fees Fruits OpCo prévus et plafonnés
-> surplus distribuable
-> Fruits / JV selon pacte
```

Nuance :

- les fees de gestion de base peuvent être payés avant les distributions si le travail est réel ;
- ils doivent être plafonnés, transparents et suspendables si le deal va mal ;
- l'upside Fruits vient après les priorités.

## Waterfall de vente

La même logique existe à la revente du bien.

```text
Prix de vente
-> frais de vente / notaire / fiscalité
-> remboursement banque senior
-> remboursement bridge / crédit vendeur / prêt UF
-> clôture ou reconstitution des réserves
-> retour du capital investisseur prioritaire
-> preferred return / rendement prioritaire dû
-> partage du surplus
-> promote / upside Fruits
```

Donc Fruits peut gagner :

- pendant la détention via les fees et le surplus de loyers ;
- à la sortie via le surplus de vente ;
- seulement après paiement des priorités.

## Ce qui se fait généralement en waterfall immobilier

Dans les JV immobilières et fonds immobiliers, la logique fréquente est :

```text
1. retour du capital investisseur
2. preferred return / hurdle : souvent 6-9%, 8% étant un repère fréquent
3. split du surplus : souvent 80/20 ou 70/30
4. promote plus élevé si performance très supérieure
```

Point très important :

```text
70/30 signifie souvent 70% investisseur / 30% sponsor.
Ce n'est pas automatiquement 70% Fruits / 30% investisseur.
```

Fourchettes défendables pour Fruits :

| Stade | Structure défendable | Lecture |
| --- | --- | --- |
| Stade 1 prudent | 80/20 investisseur/Fruits après pref | Plus facile à accepter sans track record |
| Stade 1-2 équilibré | 70/30 investisseur/Fruits après pref | Possible si deal très clair et Fruits co-investit |
| Stade 2+ value-add | 70/30 puis 60/40 après hurdle élevé | Possible si Fruits prouve une vraie création de valeur |
| Très favorable Fruits | 30/70 investisseur/Fruits | Rare en JV classique ; plutôt si investisseur est plafonné/cappé |

## 70/30 en faveur de Fruits : quand c'est possible

Un split 70% Fruits / 30% investisseur est difficile à vendre si l'investisseur prend le risque equity principal.

Il devient plus crédible dans ces cas :

- l'investisseur a une rémunération prioritaire ou plafonnée ;
- l'investisseur est remboursé avant Fruits ;
- Fruits apporte le deal, l'exécution, les travaux, la gestion, la banque et la sortie ;
- Fruits met un vrai co-investissement ;
- le 70/30 ne s'applique qu'au surplus après capital + preferred return ;
- le deal est value-add, pas core passif ;
- le risque opérationnel est majoritairement chez Fruits.

Formulation correcte :

> Après remboursement du capital investisseur et paiement du rendement prioritaire cible, le surplus peut être partagé en faveur de Fruits si la performance dépasse les seuils convenus.

Formulation à éviter :

> Fruits prend 70% de la plus-value.

La deuxième phrase donne l'impression que l'investisseur finance et que Fruits capte tout trop tôt.

## Cas par financeur

### Family Office - usufruit classique

Le 70/30 à la revente n'est pas naturel.

Pourquoi :

- le FO achète la nue-propriété ;
- Fruits achète l'usufruit ;
- à terme, le FO récupère la pleine propriété par remembrement ;
- il n'y a pas normalement de partage de plus-value à la fin.

Ce que Fruits gagne :

- les loyers nets pendant la durée de l'usufruit ;
- les fees d'OpCo si prévus ;
- éventuellement une option de rachat ou une nouvelle vente d'usufruit, si négociée.

Possibilité rare :

- si le bien est vendu avant terme, le prix peut être réparti entre NP et UF selon la convention ;
- Fruits peut négocier un success fee si sa gestion crée une valeur exceptionnelle ;
- mais ce n'est pas le produit le plus naturel pour un promote 70/30.

Conclusion :

```text
FO NP/UF = logique patrimoniale.
JV/ADP = logique promote / split.
```

### Family Office - portage d'usufruit

Possible de mieux capter l'upside si le FO agit comme prêteur ou investisseur plafonné.

Schéma :

```text
FO détient NP
+ FO finance/prête l'UF
+ Fruits exploite
+ Fruits rembourse le prêt UF
+ Fruits garde le surplus d'exploitation
```

Ici, le FO cherche surtout :

- sécurité ;
- rendement contractuel ;
- propriété finale.

Fruits peut garder plus d'upside, mais le coût du prêt privé sera souvent plus élevé.

### UHNWI / ADP / club deal

C'est le meilleur terrain pour négocier un promote.

Structure possible :

```text
capital ADP investisseur
-> rendement prioritaire cible 6-8%
-> retour du capital prioritaire
-> surplus partagé 70/30 ou 80/20
```

Version prudente :

```text
80% investisseur / 20% Fruits après pref
```

Version plus ambitieuse :

```text
70% investisseur / 30% Fruits après pref
```

Version très favorable Fruits :

```text
investisseur plafonné à un multiple ou IRR cible
-> Fruits garde 100% du surplus au-delà
```

C'est parfois plus clair qu'un 70% Fruits :

```text
Investisseur reçoit capital + pref + prime.
Au-delà, Fruits garde l'upside.
```

### Foncière privée / JV

Promote possible, mais il faut rester crédible.

Structure classique :

```text
foncière apporte capital majoritaire
+ Fruits apporte sourcing / opération / co-invest
+ pref ou hurdle pour la foncière
+ surplus partagé 80/20 puis 70/30 si performance
```

Un 70% Fruits est difficile sauf si Fruits apporte déjà l'actif, un gros co-invest ou un pipeline rare.

### Fonds core / core+

Les fonds core/core+ acceptent moins de promote agressif.

Logique :

- actifs stabilisés ;
- rendement plus bas ;
- risque plus bas ;
- fees serrés ;
- promote modéré.

Structure plus réaliste :

```text
management fee modéré
+ promote 10-20% après hurdle
+ 70/30 ou 80/20 plutôt en faveur du fonds
```

### Private debt / bridge / banques

Pas de split de plus-value normalement.

Le prêteur veut :

- intérêt ;
- frais ;
- sûretés ;
- remboursement.

Fruits garde l'upside après remboursement, mais le prêteur peut demander :

- exit fee ;
- cash sweep ;
- prepayment fee ;
- covenant strict.

### Crédit vendeur

Pas un vrai promote.

Le vendeur reçoit :

- paiement différé ;
- intérêt éventuel ;
- sûreté.

Fruits garde l'upside après paiement du vendeur.

Possible alternative :

- complément de prix / earn-out si le vendeur veut participer à une hausse future.

### Crédit-bail immobilier

Pas de split d'upside classique.

Fruits gagne si :

- l'activité supporte les loyers ;
- l'option d'achat finale est intéressante ;
- l'actif devient plus rentable après exploitation.

### Crowdfunding / PSFP

Si dette : pas de split d'upside.

Si equity/crowdequity : waterfall possible, mais il faut rester simple et très clair pour les investisseurs.

## Comment négocier le promote

Arguments qui justifient une part Fruits plus élevée :

- Fruits source un actif off-market ou décoté ;
- Fruits apporte une compétence opérationnelle réelle ;
- Fruits prend un risque travaux / locatif / exécution ;
- Fruits co-investit 5-15% ;
- l'investisseur est prioritaire et protégé ;
- les fees fixes sont faibles ;
- la performance au-delà du hurdle vient surtout du travail Fruits.

Arguments qui réduisent la part Fruits :

- l'investisseur apporte presque tout le capital ;
- actif core, simple, déjà stabilisé ;
- peu de travaux ;
- Fruits n'a pas encore de track record ;
- fees fixes déjà élevés ;
- l'investisseur prend le risque de refinancement ou de sortie.

Règle de négociation :

```text
Plus le capital investisseur est protégé et plafonné,
plus Fruits peut capter l'upside.

Plus l'investisseur prend le risque equity complet,
plus le split doit rester en faveur de l'investisseur.
```

## Structures recommandées Fruits

### Stade 1

```text
Capital investisseur remboursé en priorité
+ preferred return cible 6-8%
+ surplus 80/20 ou 70/30 en faveur investisseur
+ fees Fruits plafonnés
```

Objectif : crédibilité.

### Stade 2

```text
capital + pref investisseur
+ 80/20 jusqu'à un IRR cible
+ 70/30 au-dessus
+ promote Fruits plus fort si dépassement clair
```

Objectif : aligner performance et rémunération.

### Stade 3

```text
waterfall institutionnelle
+ hurdle
+ catch-up éventuel
+ promote par paliers
+ reporting audité
+ clawback si besoin
```

Objectif : parler le langage fonds/JV.

## Clause de protection investisseur

Pour que Fruits puisse négocier un upside, il faut rassurer :

- pas de promote avant retour du capital investisseur ;
- pas de promote avant paiement du rendement prioritaire cible ;
- pas de distribution si DSRA ou réserves non pleines ;
- fees plafonnés ;
- transactions interco à l'arm's length ;
- reporting mensuel ;
- audit possible ;
- clawback si performance calculée trop tôt.

## Phrase investisseur propre

> Fruits se rémunère d'abord comme opérateur via des fees transparents et plafonnés. L'upside Fruits ne commence qu'après paiement des charges, de la dette, des réserves et de la priorité investisseur. Si Fruits crée plus de valeur que le seuil prévu, le surplus est partagé selon une waterfall négociée.

## Phrase interne

```text
Salaire = fees OpCo raisonnables.
Upside = promote après investisseur.
Dividendes = seulement si groupe rentable.
```
