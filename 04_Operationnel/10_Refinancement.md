# Refinancement

## Objectif

Utiliser le refinancement comme outil de sortie, de baisse du coût du capital ou de recyclage partiel de cash, sans transformer Fruits en modèle dépendant d'une hausse de valorisation.

Le refinancement ne crée pas de richesse par lui-même. Il permet seulement de remplacer une dette ou de libérer une partie de l'equity si l'actif vaut plus, si les loyers couvrent la nouvelle dette et si la banque accepte le risque.

## Définition simple

Refinancer, c'est remplacer un financement existant par un nouveau financement.

On le fait pour :

- baisser le taux ;
- rallonger la durée ;
- remplacer une dette courte par une dette longue ;
- rembourser une dette chère ;
- libérer une partie du cash immobilisé si la valeur du bien a monté ;
- racheter un investisseur si le cash-flow et la valeur le permettent.

## Les 5 formes utiles pour Fruits

### 1. Renégociation bancaire

Même banque, même prêt, conditions modifiées.

Schéma :

```text
prêt existant
-> discussion avec la même banque
-> taux / durée / mensualité modifiés
-> même dette, meilleures conditions
-> DSCR amélioré si mensualité baisse
```

Usage :

- baisser le taux ;
- ajuster la durée ;
- réduire la mensualité ;
- améliorer le DSCR.

Avantage :

- souvent plus simple qu'un rachat externe.

Limite :

- la banque actuelle n'a pas toujours intérêt à donner le meilleur taux du marché.

Logique économique :

- on ne change pas forcément de banque ;
- on cherche surtout à améliorer le coût ou la durée ;
- c'est utile quand l'actif fonctionne déjà et que Fruits veut sécuriser le cash-flow.

### 2. Rachat / refinancement externe

Une nouvelle banque rembourse l'ancien prêt et met en place un nouveau prêt.

Schéma :

```text
prêt existant banque A
-> banque B propose une nouvelle dette
-> banque B rembourse banque A
-> nouvelle sûreté / nouveau contrat
-> Fruits paie banque B
```

Usage :

- obtenir un meilleur taux ;
- changer de maturité ;
- sortir d'une dette bridge ;
- améliorer les covenants.

À vérifier :

- indemnités de remboursement anticipé ;
- frais de dossier ;
- frais de garantie ;
- mainlevée / nouvelle sûreté ;
- nouveau taux ;
- assurance ;
- coût total, pas seulement mensualité.

Logique économique :

- on accepte des frais de sortie et de mise en place si le gain total est supérieur ;
- le calcul doit comparer le coût complet, pas seulement le taux affiché ;
- utile si une autre banque accepte une durée, un taux ou une structure plus adaptés.

### 3. Bridge-to-term

La dette courte d'acquisition est remplacée par une dette longue après stabilisation.

Schéma :

```text
achat rapide
-> dette bridge courte
-> stabilisation du bien
-> refinancement bancaire long terme
-> remboursement du bridge
```

Exemple :

```text
acquisition rapide avec dette bridge 18 mois
+ travaux / mise en location / rent roll propre
+ nouvelle expertise
+ refinancement bancaire 7-15 ans
+ remboursement du bridge
```

C'est la version la plus saine pour Fruits quand un actif a été acheté vite, puis stabilisé.

Logique économique :

- le bridge sert à acheter vite mais coûte plus cher ;
- la dette long terme arrive après preuves : loyers, travaux terminés, valeur confirmée ;
- Fruits transforme une dette courte risquée en dette longue plus stable.

### 4. Cash-out refinance

Nouveau prêt plus élevé que l'ancien, avec extraction d'une partie de la valeur créée.

Schéma :

```text
actif acheté / stabilisé
-> valeur du bien augmente
-> nouvelle banque prête sur la nouvelle valeur
-> ancienne dette remboursée
-> surplus net libéré après frais et réserves
```

Exemple :

```text
 ancien prêt : 300k
+ nouvelle valeur expertisée : 620k
+ nouvelle dette à 60% LTV : 372k
+ cash brut libéré : 72k avant frais/réserves
```

À retenir :

- le cash-out vient de la valeur créée, pas du hasard ;
- il augmente la dette ;
- il peut dégrader le DSCR ;
- il ne doit pas vider les réserves ;
- il ne doit pas servir à payer salaires, train de vie ou pertes d'exploitation.

Logique économique :

- le cash-out recycle une partie de la valeur créée ;
- ce n'est pas un profit immédiat : c'est une dette plus élevée ;
- il est sain seulement si le bien supporte la nouvelle mensualité.

### 5. Refinancement de pool

Plusieurs actifs stabilisés sont refinancés ensemble.

Schéma :

```text
plusieurs actifs isolés
-> historique loyers / reporting / valeurs
-> dette de portefeuille
-> remboursement des petites dettes existantes
-> coût du capital potentiellement plus bas
```

Usage :

- baisser le coût du capital ;
- remplacer plusieurs petites dettes ;
- financer une sortie investisseur ;
- créer une dette senior plus institutionnelle ;
- préparer un partenariat fonds/foncière.

Précondition :

- reporting fiable ;
- actifs homogènes ;
- rent roll propre ;
- valorisation externe ;
- covenants maîtrisés.

Logique économique :

- un pool stabilisé peut rassurer davantage qu'un actif isolé ;
- la taille permet d'intéresser des prêteurs plus institutionnels ;
- en échange, le reporting, les covenants et l'audit deviennent plus exigeants.

## Où le refinancement s'insère dans les stratégies Fruits

### Usufruit / nue-propriété

Refinancement possible surtout côté Fruits si l'usufruit est financé par dette.

Objectifs :

- remplacer une dette UF privée chère par une dette bancaire ;
- réduire le coût de financement de l'usufruit ;
- rembourser un prêt UF au FO si portage ;
- renforcer les réserves.

Attention :

- le FO nu-propriétaire ne doit pas dépendre d'un refinancement pour récupérer son actif : sa sortie naturelle reste le remembrement.

### SPV + actions de préférence

Refinancement possible après stabilisation.

Objectifs :

- racheter partiellement ou totalement les ADP ;
- remplacer une dette courte par dette longue ;
- baisser le coût moyen du capital ;
- libérer du cash pour le prochain actif.

Règle :

- le rachat ADP doit être prévu, pas garanti.
- le refinancement doit être une option, pas une obligation vitale.

### Bridge / asset-backed

Refinancement = sortie principale possible.

Objectifs :

- rembourser le bridge ;
- conserver l'actif si le cash-flow est bon ;
- éviter une vente forcée ;
- passer d'une dette chère courte à une dette long terme.

À présenter au lender dès le départ :

- valeur après travaux ;
- loyers stabilisés ;
- DSCR attendu ;
- banques cibles ;
- timing M12 / M18 / M24.

### Crédit vendeur

Refinancement possible pour rembourser le vendeur.

Objectifs :

- solder le paiement différé ;
- sécuriser la relation vendeur ;
- éviter une pression de trésorerie.

Attention :

- la banque senior doit accepter la structure et le rang du vendeur dès le départ.

### Crédit-bail immobilier

Le refinancement se fait plutôt via :

- levée d'option ;
- refinancement bancaire après levée ;
- cession-bail si Fruits détient déjà l'actif.

C'est un outil plus adapté à l'immobilier d'exploitation qu'au résidentiel pur.

## Règles Fruits avant de refinancer

Un refinancement est autorisé seulement si :

- DSCR normal > 1,30x après refinancement ;
- DSCR stress > 1,20x ;
- LTV senior reste dans la zone 55-65% ;
- DSRA reste pleine ;
- réserve capex/vacance reste pleine ;
- frais et pénalités sont inclus ;
- valorisation externe ou avis de valeur sérieux ;
- sortie alternative existe si la banque refuse.

Cash-out autorisé seulement si :

- l'actif est stabilisé ;
- loyers encaissés et non seulement projetés ;
- travaux terminés ;
- vacance/impayés sous contrôle ;
- la nouvelle dette reste supportable ;
- le cash libéré sert à rembourser une dette chère, racheter un investisseur ou financer un nouveau deal prudent.

Cash-out interdit pour :

- payer un salaire personnel ;
- combler une exploitation déficitaire ;
- distribuer à Fruits avant réserves ;
- acheter des ETF actions dans une SPV financée ;
- masquer un deal qui ne cash-flow pas.

## Formules à intégrer dans les modèles

### Nouvelle dette maximale

```text
 dette max = valeur prudente x LTV cible
```

La valeur prudente doit être la plus basse entre :

- valeur expertisée ;
- valeur de marché avec haircut ;
- valeur supportée par les loyers via DSCR.

### Cash-out net

```text
 cash-out net =
 nouvelle dette
- dette existante remboursée
- indemnités remboursement anticipé
- frais de dossier
- frais de garantie / notaire
- reconstitution DSRA
- réserve capex/vacance
```

### DSCR après refinancement

```text
 DSCR = NOI stabilisé / service annuel de la nouvelle dette
```

Si le cash-out fait passer le DSCR sous le seuil, il faut réduire le cash-out ou abandonner.

## Exemple simple

Actif acheté :

```text
 coût total : 500k
+ dette initiale : 300k
+ ADP : 150k
+ Fruits : 50k
```

Après travaux et mise en location :

```text
 valeur expertisée : 620k
+ LTV refinance cible : 60%
+ nouvelle dette possible : 372k
```

Cash brut libéré :

```text
 372k - 300k = 72k
```

Si frais + réserves = 15k :

```text
 cash-out net = 57k
```

Conclusion :

- ce refinancement peut rembourser une dette courte, renforcer Fruits ou racheter une partie des ADP ;
- il ne suffit pas à rembourser 150k d'ADP ;
- pour racheter 150k d'ADP, il faudrait une valeur beaucoup plus élevée ou une autre source de cash.

## Calcul rapide pour racheter les ADP

Si Fruits veut rembourser 150k d'ADP avec un refinancement :

```text
 dette existante : 300k
+ ADP à racheter : 150k
+ frais/réserves : 15k
= nouvelle dette nécessaire : 465k
```

Valeur nécessaire :

```text
 à 60% LTV : 465k / 60% = 775k
à 65% LTV : 465k / 65% = 715k
```

Donc un actif acheté 500k doit valoir environ 715k-775k pour permettre un rachat complet des ADP par dette seule, hors contrainte DSCR.

Conclusion :

> Le refinancement peut aider à racheter les investisseurs, mais il ne faut jamais promettre que cela sera possible.

## Timing recommandé

### À l'achat

- Modéliser le scénario de refinancement dès le départ.
- Négocier les indemnités de remboursement anticipé.
- Identifier banques de sortie.
- Éviter une dette courte sans plan B.

### Après 6-12 mois

- Stabiliser loyers.
- Corriger impayés/vacance.
- Finaliser travaux.
- Préparer rent roll et reporting.

### 6-9 mois avant maturité de dette

- Lancer discussion banques.
- Obtenir avis de valeur.
- Comparer vente vs refinancement.
- Préparer data room.

### Au closing refinance

- Rembourser ancienne dette.
- Reconstituer réserves.
- Ne distribuer que le surplus vraiment disponible.
- Mettre à jour reporting et covenants.

## Erreurs à éviter

- Acheter un actif uniquement parce qu'on espère le refinancer plus haut.
- Modéliser une valeur de sortie trop optimiste.
- Oublier frais, indemnités et nouvelle garantie.
- Racheter les investisseurs avec dette alors que le DSCR devient fragile.
- Confondre cash-out et profit.
- Attendre le dernier mois avant maturité du bridge.
- Utiliser une valorisation théorique non finançable par les loyers.

## Phrase à retenir

Le bon refinancement transforme un actif stabilisé en capital plus long et moins cher. Le mauvais refinancement transforme une hypothèse de valeur en dette certaine.
