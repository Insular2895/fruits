# Produits Fruits

## Regle centrale

Le produit standard Fruits est le co-invest operateur decrit dans [Chassis standard Fruits](00_Chassis_Standard_Fruits.md).

L'usufruit juridique n'est plus le produit par defaut. Il devient une exception utile quand l'actif est stable, la duree longue, le FO patrimonial et la fiscalite valides.

## Matrice produits

| Produit Fruits | Objectif | Structure principale | Ce que Fruits capte | Priorite |
| --- | --- | --- | --- | --- |
| Premier appartement / colocation | Track record personnel + bancaire | Achat classique, LMNP, SCI ou SPV simple selon contexte | Loyers, experience, data | Tres haut |
| Immeuble locatif optimise | Tester gestion multi-lots | Co-invest operateur | Revenus nets, fees, promote | Tres haut |
| Coliving / residence services | Actif exploite a forte valeur operationnelle | PropCo / OpCo + co-invest | Revenus operationnels, fees, upside | Tres haut |
| Condo / etudiant / mixed-use | Produit scalable premium | PropCo / OpCo + dette + investisseurs | NOI, fees, promote, data | Haut |
| Cabinet dentaire / sante infra | Plateforme d'infrastructure medicale | SPV sante / PropCo / OpCo | Fees infra, loyers, services non medicaux | Haut mais later stage |
| Marchand de biens / renovation | Marge court terme | SPV + dette + promote | Development fees, success fees, promote | Moyen a haut |
| Reprise PME BTP | Integration verticale / synergies | Co-invest PE / LBO | Monitoring fees, EBITDA uplift, carry | Moyen, later stage |
| Pool stade 2 | Industrialisation portefeuille | SPV pool + dette senior/private debt | Management fees, carry, valeur groupe | Apres 3-5 deals |
| Infrastructure longue duree | Energie, eau, foncier, actifs lourds | Droit reel long / lease / co-invest | Revenus long terme, fees, option | Plus tard |

## Application par structure

| Produit | Structure a privilegier | Usufruit juridique | Bridge / portage | Comment Fruits gagne |
| --- | --- | --- | --- | --- |
| Premier appartement | Achat classique / LMNP si pertinent | Non | Non | Loyers + track record |
| Colocation | Co-invest operateur ou achat personnel au demarrage | Rare | Oui si achat rapide | Revenus nets + fees + upside |
| Immeuble locatif | Co-invest operateur | Possible si FO patrimonial | Oui | Revenus nets + management + promote |
| Residence services | PropCo / OpCo | Possible mais pas necessaire | Oui si travaux | Revenus operationnels + fees + promote |
| Condo / etudiant | PropCo / OpCo + pool futur | Possible si long terme | Oui | NOI + fees + data + valeur patrimoniale |
| Cabinet dentaire | SPV sante + PropCo / OpCo | A cadrer fortement | Oui equipement / locaux | Fees infra + services + performance |
| Marchand de biens | SPV + dette + promote | Non | Oui | Fees travaux + marge + promote |
| PME BTP | Co-invest PE / LBO | Non | Oui acquisition | Monitoring fee + EBITDA uplift + carry |
| Infrastructure longue | Droit reel long / lease | Oui si adapte | Oui au demarrage | Revenus long terme + option + valeur |

## Roadmap produit

1. Premier appartement / colocation.
2. Immeuble locatif optimise, avec objectif portefeuille et repetition.
3. Pool immobilier Fruits apres plusieurs operations documentees.
4. Reprise PME BTP quand le socle immobilier, travaux et reporting est robuste.
5. Cabinet dentaire / sante infra comme nouvelle source de tresorerie, sans operation medicale.
6. Residence services, logement etudiant ou mixed-use smart building.
7. Infrastructure longue duree : energie, eau, carbone, foncier.

## Regle de priorite

Ne pas lancer un produit nouveau tant que le precedent n'a pas :

- modele financier ;
- term sheet ;
- documentation juridique ;
- reporting ;
- premier retour investisseur ;
- stress test ;
- decision d'exit explicite.
