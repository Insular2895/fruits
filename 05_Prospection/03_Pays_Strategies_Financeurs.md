# Pays / Stratégies / Financeurs

## Objectif

Associer chaque type de financeur aux pays où le discours Fruits est le plus naturel.

## Lecture rapide

| Pays | Financeurs naturels | Stratégie Fruits la plus adaptée |
| --- | --- | --- |
| France | FO, UHNWI, banques, BPI, Banque des Territoires, PSFP, foncières | NP/UF, ADP, SPV, immobilier opérationnel, impact territorial |
| Luxembourg | FO, holdings, fonds, banques privées | holding, fonds, dette structurée, capital international |
| Suisse | FO, banques privées, UHNWI | lombard, capital patrimonial, club deal |
| Belgique | FO, UHNWI, holdings patrimoniales | SPV, ADP, immobilier France/Benelux |
| Royaume-Uni | debt funds, family offices, advisors | private debt, preferred equity, arranger |
| Pays-Bas | fonds, institutionnels, pensions | portefeuille, ESG, reporting institutionnel |
| Allemagne | foncières, assureurs, fonds core | actifs stables, long terme, institutionnel |
| Monaco | banques privées, UHNWI | relationnel, club deal, ticket test |

## France

Meilleur fit :

- usufruit / nue-propriété ;
- SPV SAS avec actions de préférence ;
- BPI si activité éligible ;
- Banque des Territoires si impact territorial réel ;
- PSFP/crowdfunding si opération courte, simple et documentée ;
- foncières privées locales ;
- banques relationnelles.

Pourquoi :

- droit civil familier avec démembrement ;
- notaires et fiscalistes comprennent NP/UF ;
- investisseurs patrimoniaux sensibles à l'actif réel.

## Luxembourg

Meilleur fit :

- holdings ;
- fonds ;
- dette structurée ;
- family offices internationaux.

À utiliser :

- quand Fruits a un pool ;
- quand il faut structurer investisseurs internationaux ;
- pas pour compliquer les premiers deals.

## Suisse

Meilleur fit :

- family offices ;
- banques privées ;
- lombard ;
- UHNWI.

Message :

- préservation capital ;
- gouvernance ;
- reporting ;
- collatéral.

## Royaume-Uni

Meilleur fit :

- private debt ;
- preferred equity ;
- arrangers ;
- advisors real estate capital markets.

Message :

- capital stack ;
- exit ;
- security package ;
- LTV/DSCR.

## Pays-Bas / Allemagne

Meilleur fit :

- fonds immobiliers ;
- assureurs ;
- caisses ;
- foncières ;
- ESG.

Précondition :

- taille ;
- reporting ;
- stabilité ;
- gouvernance.

## Règle

Stade 1 : France, Belgique, Suisse, Luxembourg.

Stade 2 : ajouter UK et Pays-Bas.

Stade 3 : Allemagne, assureurs, institutions, fonds paneuropéens.
