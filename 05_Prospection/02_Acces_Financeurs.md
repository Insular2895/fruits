# Accès Aux Financeurs

## Objectif

Définir comment approcher chaque financeur sans perdre du temps ni paraître amateur.

## Prérequis communs

Avant toute approche :

- teaser 1 page ;
- deck 10-15 slides ;
- modèle financier ;
- data room ;
- term sheet cible ;
- CV / track record ;
- schéma juridique ;
- reporting pack exemple ;
- liste risques + mitigants.

## Outils de prospection

Aucun outil ne répertorie tous les UHNWI et tous les Family Offices. Les meilleurs profils sont souvent discrets, non publics ou accessibles seulement par réseau.

Les bases servent à créer une liste qualifiée. L'accès réel vient ensuite par introduction chaude.

### Stack budget raisonnable

- LinkedIn Sales Navigator.
- Pappers / Societe.com.
- Informations publiques INREV / MIPIM.
- Apollo ou Clay pour enrichissement contact.
- Airtable ou Notion comme CRM.

### Stack pro

- FINTRX pour Family Offices, RIAs et contacts wealth.
- Preqin ou PitchBook pour LPs, fonds, investisseurs alternatifs.
- Orbis pour holdings, structures de propriété et sociétés patrimoniales.
- Altrata Wealth-X pour UHNWI.
- INREV / MIPIM pour institutionnels immobiliers.

### Financeurs complémentaires ajoutés

Crowdfunding / PSFP :
- utile pour un deal simple, court et très documenté ;
- vérifier que la plateforme est agréée PSFP quand l'offre porte sur titres ou prêts rémunérés ;
- éviter les produits trop sophistiqués ou les promesses de rendement.

Banque des Territoires / CDC :
- pertinente si le projet répond à un enjeu territorial réel : santé, immobilier d'entreprise, transition, revitalisation, impact social ;
- peu adaptée au pur rendement résidentiel privé.

SCPI / OPCI / SIIC :
- à traiter surtout comme acheteurs de sortie ou partenaires sur actifs stabilisés ;
- très sensibles à la donnée, aux baux, à l'ESG, à la valorisation et à la taille.

Crédit vendeur :
- à tester dès l'offre d'achat quand le vendeur est motivé ;
- doit être validé par notaire, banque senior et avocat si cession de société.

Crédit-bail immobilier :
- adapté à l'immobilier d'exploitation ;
- moins naturel pour une foncière résidentielle passive.

### Méthode CRM

Champs minimum :

- nom entité ;
- type investisseur ;
- pays ;
- ticket estimé ;
- stratégie compatible : FO/NP-UF, ADP, bridge, dette, JV ;
- source du contact ;
- warm intro possible ;
- dernier contact ;
- statut : à qualifier, contacté, call, NDA, data room, term sheet, refus ;
- raison du refus ;
- prochaine action.

Règle :

> Une base de données donne des noms. Le closing vient des introductions, de la crédibilité du dossier et du suivi.

## Family Offices

Canaux :

- avocats patrimoniaux ;
- notaires ;
- banquiers privés ;
- fiscalistes ;
- clubs entrepreneurs ;
- M&A advisors ;
- réseaux suisses, luxembourgeois, belges, monégasques.

Message :

- actif réel ;
- gouvernance propre ;
- peu de gestion ;
- sortie naturelle ;
- reporting sobre.

Ce qu'il faut éviter :

- pitch trop startup ;
- promesse de rendement ;
- structure offshore opaque.

## UHNWI

Canaux :

- entrepreneurs cash-out ;
- cédants d'entreprise ;
- réseaux business angels patrimoniaux ;
- avocats M&A ;
- banquiers privés.

Message :

- deal concret ;
- ticket test ;
- priorité économique ;
- rachat prévu ;
- relation directe.

## Private debt bridge / asset-based

Canaux :

- debt brokers ;
- real estate debt advisors ;
- fonds private debt ;
- banques challenger ;
- family offices prêteurs.

Message :

- LTV ;
- sûretés ;
- sortie ;
- lockbox ;
- DSRA ;
- actif liquide.

À envoyer :

- term sheet dette ;
- valuation ;
- plan sortie ;
- budget capex ;
- rent roll.

## Foncières privées

Canaux :

- brokers investissement ;
- asset managers locaux ;
- notaires ;
- réseaux immobiliers patrimoniaux ;
- family offices immobiliers.

Message :

- compatibilité mandat ;
- zone ;
- rendement ;
- portefeuille ;
- Fruits comme opérateur.

## Banques privées

Canaux :

- relation patrimoniale ;
- introductions par avocat/notaire ;
- banque du fondateur ;
- banques suisses/luxembourgeoises/monégasques.

Message :

- collatéral ;
- KYC propre ;
- LTV basse ;
- plan margin call ;
- flux immobiliers.

## Private debt structuré

Canaux :

- debt advisors ;
- banques d'affaires ;
- fonds dette immobilière ;
- plateformes institutionnelles.

Précondition :

- 12-24 mois de KPI ;
- pool 5-10M ;
- reporting mensuel.

## Fonds core/core+

Canaux :

- brokers capital markets ;
- asset managers ;
- conférences INREV/MIPIM ;
- banques d'affaires.

Précondition :

- taille ;
- portefeuille stabilisé ;
- ESG ;
- valorisation externe.

## BPI / banques publiques

Canaux :

- banque partenaire ;
- chargé d'affaires Bpifrance ;
- expert-comptable ;
- réseau French Tech / CCI si activité éligible.

Message :

- entreprise réelle ;
- immobilier d'exploitation ou projet productif ;
- transition énergétique ;
- santé ;
- innovation.

## Banque des Territoires / CDC

Canaux :

- interlocuteur Banque des Territoires régional ;
- collectivités locales ;
- ARS pour santé ;
- CCI / agences de développement économique ;
- partenaires publics-privés ;
- foncières responsables déjà cofinancées.

Message :

- impact territorial mesurable ;
- projet long terme ;
- gouvernance propre ;
- cofinancement privé ;
- utilité locale : santé, transition, immobilier d'entreprise, revitalisation.

À éviter :

- discours purement financier ;
- arbitrage court ;
- montage offshore ;
- actif sans lien avec un besoin territorial.

## Crowdfunding / PSFP

Canaux :

- plateformes PSFP agréées ;
- plateformes immobilier ;
- cabinets spécialisés en levées retail ;
- avocats marchés financiers.

Message :

- actif simple ;
- durée courte ;
- budget et sortie lisibles ;
- risques clairement écrits ;
- reporting régulier.

À envoyer :

- teaser actif ;
- modèle simplifié ;
- note risques ;
- structure SPV ;
- sûretés possibles ;
- planning de sortie.

## SCPI / OPCI / SIIC / pierre-papier

Canaux :

- brokers capital markets ;
- sociétés de gestion ;
- asset managers ;
- ASPIM / annuaires AMF ;
- conférences immobilières.

Message :

- actif stabilisé ;
- loyers vérifiables ;
- ESG ;
- valorisation externe ;
- portefeuille vendable ;
- mandat de gestion Fruits seulement si valeur ajoutée claire.

## Crédit vendeur

Canaux :

- vendeur direct ;
- notaire ;
- agent immobilier ;
- avocat du vendeur ;
- broker immobilier.

Message :

- prix mieux défendu grâce au paiement différé ;
- calendrier clair ;
- sûreté cadrée ;
- sortie courte ;
- vendeur payé prioritairement selon waterfall après banque senior.

## Crédit-bail immobilier

Canaux :

- banque professionnelle ;
- Bpifrance ;
- BPCE Lease ;
- filiales crédit-bail des groupes bancaires ;
- expert-comptable.

Message :

- immobilier d'exploitation ;
- crédit-preneur solide ;
- usage long terme ;
- business plan capable de payer les loyers ;
- option finale claire.

## Assureurs / caisses / institutions

Canaux :

- banque d'affaires ;
- placement agent ;
- consultant institutionnel ;
- réseau asset management ;
- conférences immobilières institutionnelles.

Précondition :

- plateforme ;
- audit ;
- gouvernance ;
- portefeuille significatif ;
- reporting institutionnel.

## Banque d'affaires / arranger

Quand l'utiliser :

- dette ou equity > 5-10M ;
- pool structuré ;
- besoin de mise en concurrence ;
- financeurs institutionnels.

Comment sélectionner :

- références immobilières ;
- liste financeurs ;
- succès récents ;
- fee raisonnable ;
- pas d'exclusivité trop large.

## Cadence d'approche

1. Warm intro.
2. Teaser.
3. Call 30 minutes.
4. NDA.
5. Data room.
6. Term sheet.
7. Due diligence.
8. Closing.

## KPI de prospection

- 30 cibles qualifiées.
- 10 calls.
- 3 term sheets indicatives.
- 1 closing.

Si le ratio est inférieur, corriger le produit, pas seulement chercher plus de noms.
