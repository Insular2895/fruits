# PACK COMPLET - BANQUE D'AFFAIRES / ARRANGER

## Cible

Banques d'affaires, debt advisors, placement agents, M&A / real estate capital markets advisors.

- Ticket : mandat utile à partir de 5-10M.
- Horizon : durée du mandat 3-12 mois ; relation long terme.
- Stade Fruits : fin stade 2 / stade 3.
- Objectif : arranger une dette, une levée equity, une syndication, une vente de portefeuille ou une introduction institutionnelle.

## Produit recommandé

### Structure principale : mandat d'arrangement dette/equity

- Fruits mandate l'arranger.
- L'arranger prépare le marché, contacte les financeurs, organise le process.
- Fruits garde la décision finale.
- Rémunération : retainer + success fee.

Pourquoi c'est adapté :
- Accès à des financeurs institutionnels.
- Crédibilité process.
- Mise en concurrence.
- Aide à structurer term sheet et data room.

## Montant / délais / calibration

- 5-10M : possible avec boutique spécialisée.
- 20M+ : plus intéressant pour banques établies.
- 50M+ : process institutionnel naturel.
- Durée : 3-6 mois pour dette simple, 6-12 mois pour equity / JV.

## Package contractuel arranger-friendly

### 1. Mandate letter

- Périmètre exact.
- Dette, equity, JV, vente ou mix.
- Exclusivité ou non.
- Durée du mandat.
- Territoire / liste investisseurs.

### 2. Fees

- Retainer raisonnable.
- Success fee payable au closing.
- Tail period limité.
- Frais remboursables plafonnés.
- Pas de fee abusive avant preuve de valeur.

### 3. Confidentialité

- NDA.
- Process contrôlé.
- Liste noire / liste blanche investisseurs.
- Interdiction de diffusion non autorisée.

### 4. Materials

- Teaser.
- Investment memo.
- Financial model.
- Data room.
- Q&A log.
- Term sheet cible.

### 5. Gouvernance process

- Weekly call.
- Pipeline investisseurs.
- Feedback log.
- Version control.
- Validation avant envoi.

## Sortie / livrables

- Term sheets reçues.
- Analyse comparative.
- Négociation.
- Closing.
- Option : syndication ou refinancement futur.

## Ce qui fait dire oui

- Taille suffisante.
- Dossier propre.
- Pipeline réel.
- Sponsor coachable.
- Économie de mandat claire.

## Ce qui fait dire non

- Deal trop petit.
- Documents pas prêts.
- Sponsor veut uniquement des introductions gratuites.
- Structure incompréhensible.
- Retours financeurs déjà négatifs sans correction.

## À préparer avant approche

- Deck.
- Data room.
- Modèle financier.
- Liste financeurs déjà contactés.
- Use of proceeds.
- Term sheet cible.
- Preuve de traction / actifs.
